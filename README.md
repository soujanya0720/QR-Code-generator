#  QR Code Generator

A simple, modern, and responsive **QR Code Generator** built using **HTML, CSS, and JavaScript**. The application allows users to enter text, URLs, phone numbers, or other information and instantly generate a QR code.

Users can preview the QR code, copy the entered content, download the QR code as an image, and switch between light and dark themes.

---

##  Features

*  Generate QR codes instantly
*  Supports URLs and text
*  Copy entered content
*  Download QR code as PNG
*  Character counter
*  Clear/reset functionality
*  Light and dark mode
*  Fully responsive design
*  Input validation
*  Clean and modern user interface
*  Saves theme preference using Local Storage

---

##  Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application functionality and DOM manipulation
* **QRCode.js** – QR code generation
* **Local Storage** – Saves the user's theme preference
